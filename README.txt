국립한국교통대학교 과제제출시스템 실행 안내
========================================

1. 프로젝트 소개
----------------
이 프로젝트는 대학교 수업에서 사용할 수 있는 로컬 기반 과제 제출 및 관리 웹 시스템입니다.

주요 기능:
- 학생 회원가입 / 로그인 / 로그아웃
- 교수 관리자 로그인
- 과제 생성 / 수정 / 삭제
- 압축파일 과제 제출 및 재제출
- 선택 README.txt 첨부
- README.txt 미리보기
- 교수 제출 현황 확인
- 점수 입력, 피드백, 수정 요청
- 과제 Q&A, 제출물 댓글
- 학생별 제출 현황
- CSV 학생 등록
- 제출 파일 ZIP 일괄 다운로드
- DB 및 제출 파일 백업


2. 실행 전 필요 프로그램
-----------------------
아래 프로그램이 설치되어 있어야 합니다.

- Node.js 18 이상 권장
- npm

Node.js 확인:

  node -v

npm 확인:

  npm -v


3. 압축 해제 위치
----------------
압축을 푼 뒤 프로젝트 폴더로 이동합니다.

예:

  cd /d F:\vibecoding

다른 위치에 압축을 풀어도 실행은 가능하지만, 기본 설명은 F:\vibecoding 기준입니다.


4. 최초 설치 방법
----------------
처음 실행하는 경우 아래 명령을 한 번 실행합니다.

  npm run install:all

이 명령은 루트, server, client 의존성을 모두 설치합니다.


5. 실행 방법
------------
개발/시연용 실행:

  npm run dev

또는 Windows에서 아래 파일을 실행해도 됩니다.

  start.bat

실행 후 브라우저에서 접속:

  http://127.0.0.1:228

같은 네트워크의 다른 PC나 모바일에서 접속하려면 실행 로그에 표시되는 내부망 IP를 사용합니다.

예:

  http://192.168.0.10:228

포트는 228번을 사용합니다.


6. 운영형 단일 서버 실행
----------------------
프론트엔드를 빌드한 뒤 Express 서버 하나로 실행하려면 아래 명령을 사용합니다.

  npm start

이 경우에도 접속 주소는 동일합니다.

  http://127.0.0.1:228

8. 제출 파일 안내
----------------
학생은 과제 상세 화면에서 압축파일을 제출합니다.

지원 예시 확장자:

  .zip, .7z, .rar, .tar, .tar.gz, .tgz, .gz

README.txt는 선택 제출입니다.
README.txt에는 압축파일 안의 파일 실행 방법, 빌드 방법, 주의사항 등을 작성하면 됩니다.


9. 데이터 저장 위치
------------------
SQLite DB:

  data\database\app.sqlite

제출 파일:

  data\submissions\

제출된 파일은 실제 로컬 파일 시스템에 저장됩니다.


10. 주요 명령어
---------------
의존성 설치:

  npm run install:all

개발 실행:

  npm run dev

운영형 실행:

  npm start

기본 기능 테스트:

  npm run smoke

추가 기능 테스트:

  npm run smoke:features


11. 문제 해결
-------------
1) 228 포트가 이미 사용 중인 경우
   다른 실행 중인 서버를 종료한 뒤 다시 실행합니다.

2) 같은 네트워크에서 접속이 안 되는 경우
   Windows 방화벽에서 Node.js 또는 TCP 228 포트 인바운드 허용이 필요할 수 있습니다.
   학교/기관 네트워크 정책상 기기 간 접속이 막혀 있으면 내부망 접속이 제한될 수 있습니다.

3) node_modules 오류가 나는 경우
   아래 명령을 다시 실행합니다.

     npm run install:all

4) DB를 초기화하고 싶은 경우
   서버를 종료한 뒤 아래 파일/폴더를 삭제하고 다시 실행합니다.

     data\database\app.sqlite
     data\submissions\

   서버 시작 시 기본 DB와 seed 데이터가 자동 생성됩니다.


12. 구현 기술
-------------
- Frontend: React, Vite, Axios
- Backend: Node.js, Express
- Database: SQLite
- File Storage: Local File System
- Authentication: JWT Cookie, bcrypt password hash
